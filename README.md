# Función para calcular el total de una compra

**Nombre del estudiante:** Jonathan Oswaldo Chicaiza Andrango

## Descripción

Este proyecto fue realizado en Python para calcular el total de una compra. La función recibe el precio de un producto y la cantidad que lleva el cliente, realiza la multiplicación y devuelve el resultado.

## Ejemplo

Precio: 5 dólares  
Cantidad: 3 productos  
Total: 15 dólares
